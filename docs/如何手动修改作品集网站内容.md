# 如何手动修改作品集网站内容

本项目为 Next.js 静态作品集网站。大部分页面文案集中在数据文件中，无需修改页面组件即可更新内容。

---

## 1. 打开项目

```
cd my-portfolio
```

## 2. 启动本地预览

```bash
npm install      # 首次需要安装依赖
npm run dev      # 启动开发服务器，默认 http://localhost:3000
```

## 3. 修改首页个人介绍

编辑文件：`src/data/profile.ts`

可修改字段：
- `name` — 姓名
- `role` — 角色标题
- `bio` — 个人介绍段落数组
- `techStack` — 技术标签数组

## 4. 修改项目顺序

编辑文件：`src/data/projects.ts`

该文件导出 `projects` 数组，数组中的顺序即为展示顺序。调整对象位置即可改变项目排列。

每个项目的 `number` 字段（如 `"01"`、`"02"`）用于显示编号，需手动同步修改。

首页展示权重由 `displayMode` 控制：
- `featured` — 第一主项目，目前为「听到了咩」
- `secondary` — 第二重点项目，目前为「ProdDoc AI」
- `experiment` — 弱化展示的实验项目，目前为「AI Decision Copilot」

如需调整展示权重，优先修改 `src/data/projects.ts` 中对应项目的 `displayMode`，不要直接改页面组件。

## 5. 修改听到了咩（heard-sheep）文案

### 项目基本信息

编辑文件：`src/data/projects.ts`，找到 `title: "听到了咩"` 的条目。

可修改字段：
- `title` — 项目名称
- `subtitle` — 中文副标题
- `englishSubtitle` — 英文辅助标题
- `description` — 首页和详情页顶部简介
- `longDescription` — 详情页"项目定位"区域的多段文字
- `tags` — 技术标签
- `github` — GitHub 链接
- `demoUrl` — 线上演示地址（为空则隐藏）
- `features` — 核心功能列表（标题 + 描述）
- `techStack` — 技术栈分组
- `pages` — 页面结构列表
- `status` — 当前状态说明

### 问题场景与产品流程

编辑文件：`src/data/content/heard-sheep.ts`

可修改字段：
- `problemScenarios` — 问题场景列表
- `productFlow` — 核心流程步骤
- `problemNote` — 补充说明文字

## 6. 修改 ProdDoc AI 文案

编辑文件：`src/data/projects.ts`，找到 `title: "ProdDoc AI"` 的条目。

字段结构与听到了咩相同。

## 7. 替换项目截图

### 听到了咩截图

存放目录：`public/projects/heard-sheep/`

当前文件：
- `home-mobile.png` — 首页录音入口
- `input-mobile.png` — 粘贴转写稿输入
- `analysis-result-mobile.png` — AI 分析结果
- `candidate-tasks-mobile.png` — 候选任务
- `tasks-with-data-mobile.png` — 任务列表（有数据）
- `tasks-mobile.png` — 任务列表（空状态）
- `task-detail-mobile.png` — 任务详情
- `history-mobile.png` — 历史记录
- `me-mobile.png` — 个人中心

替换同名文件即可自动生效。如需增减截图，同步修改 `projects.ts` 中 `screenshots` 数组。

### ProdDoc AI 截图

存放目录：`public/screenshots/proddoc-ai/`

## 8. 修改 GitHub、邮箱、链接

编辑文件：`src/data/site-config.ts`

可修改字段：
- `email` — 联系邮箱（设为 `null` 则不显示）
- `github` — GitHub 链接
- `url` — 网站 URL

编辑文件：`src/data/navigation.ts`

可修改字段：
- `main` — 顶部导航链接
- `footer` — 底部导航链接

## 9. 修改后预览与检查

```bash
npm run dev        # 本地预览，浏览器打开 http://localhost:3000
npm run build      # 构建检查，确认无报错
npx tsc --noEmit   # TypeScript 类型检查
```

线上站点当前部署在 `https://heard-sheep.cloud/`。合并到 `main` 并完成生产部署后，根路径展示作品集，`/sheep` 保留听到了咩真实产品。

生产部署记录与回滚信息维护在：

```text
docs/上线执行记录_作品集网站_heard-sheep-cloud.md
```

## 10. 修改项目体验入口

编辑文件：`src/data/projects.ts`

每个项目有以下体验相关字段：
- `tryPath` — 体验 Demo 路径（如 `/try/proddoc-ai`），设为 `null` 则不显示体验按钮
- `tryLabel` — 体验按钮文案（如 "体验 Demo"、"立即体验"）
- `experienceTag` — `/try` 页面中的标记（如 "真实产品体验"、"交互演示"）
- `experienceDescription` — `/try` 页面中的说明文字

## 11. 修改听到了咩真实产品地址

编辑文件：`src/data/site-config.ts`

修改 `heardSheepLiveUrl` 字段：
- 开发环境默认：`http://localhost:3001/sheep`
- 自有服务器生产默认：`/sheep`
- Vercel 预览或临时外部产品地址：设置环境变量 `NEXT_PUBLIC_HEARD_SHEEP_URL`

不要在不同页面分别硬编码 heard-sheep 地址；首页、`/try`、`/projects/heard-sheep` 都应读取同一个配置源。

## 12. 修改 ProdDoc AI Demo 内容

编辑文件：`src/data/demos/proddoc-ai.ts`

可修改：
- `defaultFormValues` — 默认表单内容
- `productTypes` — 产品类型选项
- `docTypes` — 文档用途选项
- `generateDocument` — 本地模板生成函数（修改输出格式和内容）

## 13. 修改 Decision Copilot 预设案例

编辑文件：`src/data/demos/decision-copilot.ts`

可修改：
- `presetCases` — 预设决策问题数组，每个案例包含问题、方案、评估维度、推荐结论和风险提示

## 14. 隐藏某个 Demo 入口

在 `src/data/projects.ts` 中将对应项目的 `tryPath` 设为 `null` 即可隐藏体验按钮。

## 15. 文件结构速查

```
src/data/
├── site-config.ts      # 网站名称、URL、邮箱、关键词、体验入口配置
├── profile.ts          # 个人介绍、技术标签
├── navigation.ts       # 顶部和底部导航链接
├── projects.ts         # 所有项目数据（顺序、文案、截图、功能、体验入口）
├── content/
│   └── heard-sheep.ts  # 听到了咩详情页补充内容
└── demos/
    ├── proddoc-ai.ts       # ProdDoc AI Demo 表单默认值与模板
    └── decision-copilot.ts # Decision Copilot 预设案例

src/app/
├── page.tsx            # 首页组件
├── layout.tsx          # 全局布局（Header / Footer）
├── try/
│   ├── page.tsx             # 体验入口汇总页
│   ├── proddoc-ai/page.tsx  # ProdDoc AI 交互 Demo
│   └── decision-copilot/page.tsx  # Decision Copilot 实验 Demo
└── projects/
    ├── heard-sheep/page.tsx    # 听到了咩详情页
    ├── proddoc-ai/page.tsx     # ProdDoc AI 详情页
    └── decision-copilot/page.tsx  # Decision Copilot 详情页

public/
├── projects/heard-sheep/   # 听到了咩产品截图
├── screenshots/portfolio/  # 作品集本地验收截图
├── screenshots/production/ # 正式域名上线验收截图
└── screenshots/proddoc-ai/ # ProdDoc AI 截图
```

## 16. 上线后需要同步检查的内容

修改首页、项目文案、截图或体验入口后，至少检查：

```bash
npx tsc --noEmit
npm run build
npm run lint
```

若变更会影响公开展示截图，重新生成并复核：

```bash
npm run screenshots
```

生产结构保持不变：

```text
https://heard-sheep.cloud/      # 作品集
https://heard-sheep.cloud/sheep # 听到了咩真实产品
```

不要把 `.env`、`.env.local`、服务器配置全文、证书私钥、SSH 私钥或任何 API Token 提交到仓库。
